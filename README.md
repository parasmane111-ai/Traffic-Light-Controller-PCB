# Traffic Light Controller using Digital Logic and PCB Design

This project implements a two-way traffic light controller using basic digital logic ICs.  
The circuit is designed and simulated in Proteus, and the PCB layout is designed using KiCad.

## Features
- 555 timer based clock generation
- 7490 counter for timing sequence
- D flip-flop based state control
- Logic gates for red, yellow, and green signal generation
- PCB design suitable for hardware implementation

## Tools Used
- Proteus for schematic simulation
- KiCad for PCB design
- Digital ICs: 555 Timer, 7490, 7474, 7408, 7432, 7404, 7486

## Applications
- Digital electronics learning project
- Traffic signal control demonstration
- PCB design practice
